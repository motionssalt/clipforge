# --- Local vision-assist stack (CPU only, no external APIs) ------------------
# These power scripts/character_index.py so face tracking / clustering is
# done deterministically on the runner, not by burning AI-vision tokens.
# Everything below is free, offline once installed, and CPU-only.
#
# InsightFace + onnxruntime carry the SCRFD face detector and the
# MobileFaceNet embedder used by the `buffalo_sc` bundle (~30 MB total).
# opencv-python-headless is the image I/O layer InsightFace uses.
# scikit-learn provides the agglomerative clustering used to group
# embeddings into stable identities. numpy is a transitive dep that we
# pin loosely so newer InsightFace versions can pull a compatible line.
insightface==0.7.3
onnxruntime==1.17.3
opencv-python-headless>=4.8,<5
scikit-learn>=1.3,<2
numpy>=1.24,<3
